# Bobby CI

> **Archived.** Bobby CI is no longer being developed. This page stays up so older links still lead somewhere.

Bobby CI was our self-hosted build system. One command turned any machine into a build runner, even behind NAT or a VPN, and you put together build, test and deploy stages on a visual canvas instead of writing YAML. Every build ran on your own machine, so your code never left it.

## What archived means

We've stopped adding features and fixes to Bobby CI, and we don't take new projects on it.

## What we're working on now

- [Ucelot](/products/ucelot) reads your repositories and documents and answers with sources.
- [Component Zoo](/products/component-zoo) runs your React components on a live canvas.

See [About Bobby](/docs/introduction) for the rest of what we do.
